## Claim

Input-first immersion does not claim that output is unimportant. It claims that output should not become the main engine too early, because production without an internal language model easily turns into translation and faulty habits.[^source-notes]

First, learners need a great deal of understood input. This builds a feel for how the language sounds, which forms occur together, and which expressions are natural in which situations.

Output then becomes more fertile: instead of producing from empty rule knowledge, learners try to send an already developed feel for the language through the mouth or hand.

## Why It Matters

The dispute between input and output becomes a question of sequence. Input builds material and intuition; output later adds activation, testing, and automation.

[^source-notes]: Source notes: Matt vs Japan und Refold zu Immersion; Input Output und Interaction in der Sprachakquisition.
