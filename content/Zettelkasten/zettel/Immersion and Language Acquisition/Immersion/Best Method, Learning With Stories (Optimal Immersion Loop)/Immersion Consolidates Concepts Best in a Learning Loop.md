## Claim

Immersion consolidates concepts best in a learning loop that lets the same material return through several modes.

A word or structure becomes more stable when it is first noticed, then encountered in listening or reading, looked up when necessary, retrieved again, and eventually used in output. Each pass adds a different kind of access instead of merely repeating the same card.

## Why It Matters

A strong loop turns individual learning events into connected language knowledge. Anki, learning lists, stories, listening, and output support one another instead of competing for attention.
