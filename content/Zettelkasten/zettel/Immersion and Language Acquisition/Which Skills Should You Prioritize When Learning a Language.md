# Which Skills Should You Prioritize When Learning a Language

## Claim

You should prioritize the skills that matter most for moving inside the target culture.

1. Understanding everyday spoken language.
2. Using spoken language yourself.
3. Reading along with spoken media, for example subtitles in YouTube videos.
4. Reading written language until literature, newspapers, and other culturally dense texts become accessible. This is the north star of immersion.

Very low priority:

1. Writing on a computer, especially email; AI can remove much of the friction here.
2. Writing literary texts on a computer.
3. Handwriting.

Handwriting is a special case for languages with character-based writing systems. For Japanese or Chinese, you do not need to produce characters perfectly by hand in order to move well inside the culture. Some handwriting can help memory, but full productive mastery of every character would take too much time. Its main value is as a memory support, not as a performance goal.
