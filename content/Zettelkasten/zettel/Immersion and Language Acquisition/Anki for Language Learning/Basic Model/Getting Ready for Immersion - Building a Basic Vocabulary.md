# Getting Ready for Immersion - Building a Basic Vocabulary

## Claim

At the beginning, Anki helps build enough basic vocabulary for immersion to become possible and increasingly comprehensible.

## Why It Matters

Anki prepares immersion; it does not replace it. A basic vocabulary creates the first recognizable anchors from which real input can build a feel for the language.
