# Output Second - Output Makes Immersion Testable

## Claim

Output reveals where the internal language model still fails. While speaking or writing, learners suddenly notice which form is missing, which collocation cannot be retrieved, or which structure was known only passively.[^source-notes]

Output is therefore not merely a test after learning. It is itself a learning event: it creates noticing, invites feedback, and forces meaning into concrete linguistic form.

## Why It Matters

Output should not consume immersion time, but it should occur regularly enough to reveal blind spots. Good immersion does not stop at comprehension; it tests whether what was understood has become flexible.
